# Scene to Seoul (STOS)

![서울을 담은 STOS 로고](logo/서울을%20담은%20STOS%20로고.png)

MJU AI Creative Idea Hackathon 2026 · AI × K-콘텐츠: Local to Global

**Scene to Seoul은 K-드라마·영화·예능·웹툰 등에서 본 장면이나 음식이 궁금한 해외 팬에게, 그 문화의 의미를 설명하고 서울에서 실제로 경험할 수 있는 장소와 이동 방법을 연결해 주는 AI 서비스다.**

줄여서 **STOS**. 서울의 K-콘텐츠 장소를 보여주는 지도에서 끝나지 않는다. 해외 이용자가 콘텐츠에서 발견한 장면·음식·분위기를 서울에서 직접 경험하도록 연결한다. 서울의 지역 자원을 출발점으로 삼고, 해외 팬이 자기 언어로 이해한 뒤 찾아갈 수 있게 만든다.

핵심은 보고 끝나는 정보가 아니라, **서울에서 해볼 수 있는 경험**으로 바꾸는 것이다.

> 우리는 K-콘텐츠를 설명하는 AI를 만드는 것이 아니라, K-콘텐츠에서 생긴 호기심을 서울에서의 실제 문화 경험으로 바꾸는 서비스를 만듭니다.

## 이용자는 어떻게 쓰는가

첫 화면에서 세 가지 중 하나로 시작한다.

| 시작 | 이용자가 원하는 것 |
| --- | --- |
| 장면 찾기 | 이 장면의 실제 장소에 가보고 싶어요. |
| 분위기 경험하기 | 드라마 속 대학가 분위기를 느껴보고 싶어요. |
| 음식 알아보기 | 이 음식이 뭔지 알고, 서울에서 먹어보고 싶어요. |

입력은 문장으로 받는다. 사진도 받을 수 있다. 사진 한 장만으로 작품명이나 촬영지를 항상 알아낼 수는 없으므로, 작품명을 함께 입력하거나 AI가 "이 작품이 맞나요?"라고 확인하는 흐름을 둔다.

### 예시 A — 실제 드라마 장소를 찾고 싶을 때

> "이 드라마 장면에 나온 곳이 어디야? 가보고 싶어."

1. 이용자가 작품명과 장면 설명, 또는 사진을 입력한다.
2. AI가 작품·장면의 단서를 파악한다.
3. 출처를 확인한 촬영지 데이터에서 해당 장소를 찾는다.
4. 지도에 장소를 표시하고 가는 길을 연결한다.
5. 결과에 **실제 촬영지 확인됨**과 확인 출처를 표시한다.

확인된 자료가 없으면 촬영지를 추측해서 말하지 않는다. 그때는 이렇게 전환한다.

> 실제 촬영지는 확인되지 않았지만, 비슷한 분위기를 경험할 수 있는 서울 장소를 보여드릴까요?

### 예시 B — 그 장면 같은 분위기를 경험하고 싶을 때

> "드라마에서 친구들이 대학가에서 놀던 분위기를 느껴보고 싶어."

AI는 이 문장을 대학가, 친구와 함께하는 일상, 음식, 거리 분위기 같은 요소로 해석한다. 그다음 등록된 서울 지역·장소 중 맞는 곳을 지도에 보여 준다.

신촌 일대를 제안한다면 "이 드라마의 촬영지"라고 주장하지 않는다. **비슷한 대학가 문화를 경험할 수 있는 지역**이라고 명확히 표시한다.

### 예시 C — 콘텐츠에서 본 음식을 먹어보고 싶을 때

> "이 장면에서 먹는 빨간 음식이 뭐야?" 또는 음식 사진 업로드

AI가 음식 후보를 식별하고, 불확실하면 이용자에게 확인을 받는다. 떡볶이로 확인됐다면 결과는 이렇게 구성한다.

- **한국어 이름:** 떡볶이
- **발음·표기:** 외국인이 주문할 때 보여줄 수 있는 한국어 이름
- **문화 설명:** 어떤 종류의 음식인지, 한국에서 보통 어떤 상황에서 즐기는지
- **주문 도움말:** "떡볶이 하나 주세요"처럼 현장에서 쓸 수 있는 짧은 표현
- **서울에서 경험하기:** 확인한 떡볶이 판매 장소를 지도에 표시
- **이동:** 현재 위치에서 선택한 장소까지 지도 앱으로 길 안내

음식 이름을 알려주는 데서 끝나지 않고, 이해 → 주문 → 실제 방문으로 이어진다.

## 실제 촬영지와 비슷한 경험을 구분한다

결과의 신뢰도는 이 구분에서 결정된다. 결과 카드마다 아래 유형을 표시한다.

| 결과 유형 | 뜻 | 표시 문구 |
| --- | --- | --- |
| 실제 촬영지 | 작품과 장소의 연결이 자료로 확인됨 | 실제 촬영지 · 출처 확인 |
| 유사 경험 장소 | 촬영지는 아니지만 음식·문화·분위기를 경험할 수 있음 | 이 장면과 비슷한 경험 |
| 확인 불가 | 작품·장소를 정확히 특정할 근거가 부족함 | 실제 촬영지는 확인되지 않았어요 |

사진으로 장소를 그럴듯하게 추측하더라도, 확인되지 않은 곳을 실제 촬영지라고 표시하지 않는다. 발표에서 이 구분을 강조하면 "AI의 환각을 어떻게 막을 건가요?"에 답할 수 있다.

## AI는 어디에 쓰이는가

AI의 역할은 장소를 만들어 내는 것이 아니다. 이용자의 막연한 관심사를 검색 가능한 문화적 요소로 해석하고, 준비된 장소 데이터와 연결한다.

```text
"드라마에서 친구들이 길거리 음식을 먹던 활기찬 곳"
        ↓ AI가 의미 분석
K-드라마 / 길거리 음식 / 친구와의 일상 / 활기찬 거리
        ↓ 장소 데이터와 비교
관련 서울 장소 후보와 음식 정보
        ↓ 서비스 기능
지도 표시 / 결과 유형 표시 / 문화 설명 / 길 안내
```

사진 입력이 있으면 AI는 음식·장소의 시각적 단서를 읽는다. 사진만으로 작품명과 정확한 촬영지를 특정하는 일은 난도가 높으므로, 해커톤에서는 **문장 입력을 핵심 기능**으로 완성하고 사진 입력은 지원 범위를 좁힌다.

## "그냥 ChatGPT에 물어보면 되지 않나요?"

일반 AI에도 드라마 장면이나 한국 음식에 대해 질문할 수 있다. Scene to Seoul은 답변만 생성하지 않는다. 확인된 작품·음식·서울 장소 데이터를 연결하고, 실제 촬영지와 유사 경험 장소를 구분하며, 지도에서 방문 장소를 선택하고 길을 찾는 과정까지 하나의 서비스로 제공한다.

| | 이용자가 하는 일 |
| --- | --- |
| 일반 AI 질문 | "이 음식이 뭐야?"에 대한 설명을 읽고, 식당을 다시 검색하고, 위치를 따로 확인한다. |
| Scene to Seoul | 음식 확인 → 한국어 이름과 문화 설명 → 확인된 서울 장소 선택 → 지도에서 방문까지 이어진다. |

차별점은 AI를 쓴다는 사실 자체가 아니다. AI의 해석을 **검증된 지역 데이터와 실제 행동**으로 연결하는 설계다. 지도만 붙이거나 AI가 장소를 임의로 추천하면 이 차별성은 약해진다.

## 해커톤에서 만들 범위

장기적으로는 드라마·영화·웹툰·게임·숏폼과 K-푸드·K-뷰티까지 확장할 수 있다. 시연에서 그 모든 콘텐츠를 다루겠다고 하면 구현이 어려워진다.

**MVP:** K-드라마·영화 속 음식과 생활 장면 → 서울에서 경험할 장소 찾기

- 문장 입력 한 가지를 확실히 구현한다.
- 음식·대학가·시장 등 문화 경험 유형 2~3개를 지원한다.
- 서대문구·신촌을 중심으로, 실제로 확인한 서울 장소 소수만 등록한다.
- AI 분석 결과에 따라 서로 다른 장소 카드와 지도 핀이 나타나게 한다.
- 결과 카드에 문화 설명, 결과 유형, 정보 출처, 길 안내 버튼을 넣는다.
- 실제 촬영지 기능은 검증된 사례가 확보된 경우에만 시연한다.

사진 분석, 실시간 영업 여부, 서울 전역의 모든 장소, 모든 작품 검색은 이후 확장 기능으로 둔다. 장소 정보가 최신인지 확인할 수 없으면 영업 여부를 확정적으로 표시하지 않는다.

## 팀에 전달할 기획 문구

**서비스명:** Scene to Seoul — K-콘텐츠에서 본 장면을 서울의 경험으로

**기획 배경:** 해외 팬은 K-드라마·영화·예능·웹툰을 통해 한국의 음식과 일상문화에 관심을 갖지만, 콘텐츠에서 본 경험을 서울 어디에서 어떻게 해볼 수 있는지 찾으려면 여러 서비스를 오가며 검색해야 합니다.

**서비스 개요:** 이용자가 기억나는 장면, 먹어보고 싶은 음식, 경험하고 싶은 분위기를 문장 또는 사진으로 입력하면 AI가 작품·음식·문화 요소를 분석합니다. 서비스는 검증된 콘텐츠·서울 장소 데이터를 바탕으로 실제 촬영지 또는 비슷한 문화를 경험할 수 있는 장소를 구분해 지도에 표시합니다. 결과에는 한국어 이름, 문화적 맥락, 장소 정보와 길 안내를 제공합니다.

**핵심 차별점:** 단순한 AI 답변이나 관광지 추천이 아니라, K-콘텐츠 속 관심사 → 문화 이해 → 확인된 서울 장소 → 실제 방문을 하나의 흐름으로 연결합니다.

**해커톤 구현 범위:** 문장 입력, AI 문화 요소 분석, 등록된 서울 장소와의 연결, 지도 결과 표시를 우선 구현합니다. 서대문구를 중심으로 소수의 사례를 정확히 시연하고, 사진 인식과 콘텐츠 범위 확대는 확장 계획으로 제시합니다.

**글로벌 확장성:** 이용자의 언어로 한국 문화를 이해하도록 돕되, 서울 로컬 장소 방문이라는 실제 행동으로 이어지게 합니다. 이후 다른 서울 지역과 K-푸드·K-뷰티·웹툰·게임 등으로 경험 유형을 확장할 수 있습니다.
